# ELSESTAR public information site

Public homepage, privacy policy and terms for ELSESTAR's YouTube application.

- Homepage: https://soheil-navvabi.github.io/
- Privacy: https://soheil-navvabi.github.io/privacy.html
- Terms: https://soheil-navvabi.github.io/terms.html

Static HTML and CSS, hosted by GitHub Pages from the root of `main`. No build tools,
analytics, sign-in or paid hosting are used. Artwork is the owner's approved
promotional image; it is not a gameplay capture.

This repository contains only public website content. The game, deployment
automation, credentials and saves belong to the separate private repository.
Do not copy private files or secrets into this repository.

To update the site, edit the HTML/CSS, check the pages on desktop and mobile, then
commit and push. Keep the policy's effective date and actual data practices current.
Retain any Google Search Console verification file or meta tag to preserve ownership.
